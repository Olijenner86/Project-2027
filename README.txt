PROJECT 2027 APP
44-week colourful PWA for Edinburgh Marathon (30 May 2027) and full-distance Ironman Leeds (15 August 2027). Includes two pool swims, three bikes, three runs, optional brick run, tick-off boxes, saved progress and notes, countdown, and shift-pattern guide. Upload all files to your GitHub Pages repository and commit to main. Garmin sync is not connected; it requires API access and a backend.
NEW IN THIS VERSION: each planned session has editable Actual distance, Actual time, and Notes fields. Values are saved locally on the device. Replace all files in the GitHub Pages repository and commit to main; then close and reopen the Home Screen app.

FIXED VERSION: repairs a JavaScript syntax error that stopped the app loading. Cache version updated so the installed PWA can refresh.
